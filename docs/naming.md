- 初查（2026-11-04）：speakorb.app / speakorb.dev 可注册；GitHub 上没有同名项目，`speakorb` 账号名可用；App Store（美区、中国区，iPhone 和 Mac）和 Homebrew 都没有同名；网页搜索没有同名产品。
