# Speakorb Bench（中文听写评测）

目标：先达到同类开源工具的中文听写水平，再逐版提高；数据、脚本和成绩都公开可复现。

## 数据

- 100 条真实口述（5 名说话人）+ 10 条负样本（静音/噪声）
- 每条两份标注：逐字金标（verbatim）+ 理想成品（ideal）
- 切分：60 条公开（CC-BY-4.0）+ 40 条留出（永不公开，防过拟合）

## 指标

| 指标 | 口径 | 目标 |
| --- | --- | --- |
| 直接可用率 | 0–5 分 ≥4 的比例 | ≥85%（云）/ ≥75%（本机） |
| 信息保真 | 漏字/改意/加料比例 | ≥99% |
| 术语召回 | 90 个常用词（人名、产品名、地名） | ≥85/90 |
| 延迟 | 松手→上屏 P50/P90 | ≤2.5s / ≤6s |

## 采集

见 `manifest.example.jsonl`；录音建议 5–40 秒、安静环境、自然说话。标注规范与评分表会随第一批数据一起公开。

> 当前仓库只有协议骨架；数据采集需要真人录音，尚未开始。
